# مرسم (Marsam) — لوحة رسم جماعية

## هيكل المشروع

```
marsam/
├── backend/          # سيرفر Node.js + Socket.io  →  يُنشر على Render
│   ├── server.js
│   └── package.json
└── frontend/         # موقع ثابت (HTML/CSS/JS)     →  يُنشر على Vercel
    ├── index.html    # الصفحة الرئيسية
    ├── room.html     # صفحة الغرفة/اللوحة
    ├── css/
    ├── js/
    │   └── config.js # ⚠️ عدّل رابط الباك اند هنا
    └── assets/
        └── logo.png
```

## خطوات النشر

### 1) رفع الكود على GitHub
ارفع مجلد `marsam` كاملًا (بمجلديه) إلى مستودع جديد في حسابك (vizek920).

### 2) نشر الباك اند على Render
1. Render → New → Web Service → اختر المستودع
2. **Root Directory**: `backend`
3. **Build Command**: `npm install`
4. **Start Command**: `npm start`
5. بعد النشر، انسخ الرابط اللي يعطيك ياه Render (مثل `https://marsam-backend.onrender.com`)

### 3) نشر الفرونت اند على Vercel
1. Vercel → New Project → اختر نفس المستودع
2. **Root Directory**: `frontend`
3. **Framework Preset**: Other (Static)
4. قبل الرفع، افتح `frontend/js/config.js` وحط رابط Render يلي نسخته:
   ```js
   window.MARSAM_BACKEND_URL = "https://marsam-backend.onrender.com";
   ```
5. انشر

### ملاحظة مهمة عن Render (الخطة المجانية)
الخطة المجانية بتنام السيرفر بعد فترة عدم استخدام، وأول طلب بعد النوم ياخذ كم ثانية. لو الفعالية مهمة، افتح الموقع قبلها بدقيقتين عشان "توقظ" السيرفر.

## الحالة الحالية (MVP + إضافات)

✅ غرف خاصة وعامة، رسم لحظي، عداد المتواجدين
✅ صلاحيات المضيف (تحويل مستخدم لوضع "مشاهدة فقط")
✅ طبقات (كل مستخدم له طبقة، تقدر تخفيها من عندك)
✅ تسجيل وإعادة تشغيل الرسم (Replay)
✅ مشاركة سريعة (رابط + QR)
✅ معرض عام (لقطات ينشرها المستخدمين)
✅ تحدي رسم سريع يبدأه المضيف
✅ تفاعلات إيموجي، مؤشرات ملونة بأسماء المستخدمين

## ملاحظات تقنية مهمة قبل الفعالية

- **التخزين حاليًا في الذاكرة فقط** (لا يوجد Supabase مربوط بعد) — يعني لو السيرفر أعيد تشغيله، تختفي الغرف والرسومات. كافي لفعالية لكن مو دائم.
- الغرف الفارغة تُحذف تلقائيًا بعد 5 دقائق من خروج آخر شخص.
- جرّب الموقع بنفسك مع صديق قبل الفعالية بيوم على الأقل للتأكد من أن Render ما يعطي مشاكل.
